Packslip: a manifest for your move.

Packslip is the small planning tool behind this blog. Log a box, give it a weight class and a destination, and Packslip suggests where it sits in the load order — before the truck backs up to the door.

What Packslip tracks

6 Tools
01

Box Manifest

Log the contents, weight class, and destination room for every box before it's sealed, so nothing gets packed on memory alone.

02

Load Order Planner

Once boxes are logged, Packslip arranges them into a suggested sequence for loading — heaviest and most stable first.

03

Route Mapper

Mark the shortest clear path from each room to the door, so the walking route is decided once instead of re-guessed on the day.

04

Weight Balance View

A simple flag for any box that looks small but carries a disproportionate weight, so it doesn't end up at the top of a stack by accident.

05

Zone Labels

Generate a short code for each box — zone, weight class, sequence number — instead of a vague word like "kitchen" on the side of the tape.

06

First-Night List

Bookmark the handful of boxes that should be the easiest to find on the first night, separate from the rest of the manifest.

How It Works

Three steps, in the order they matter.

Log each box

As you pack, note what's inside, roughly how heavy it feels, and where it's headed. Takes seconds per box.

Generate a load order

Packslip sorts the manifest into a suggested loading sequence, grouped by weight class and destination.

Follow the manifest

On moving day, work the list top to bottom instead of grabbing whatever box is nearest the door.

Mini-FAQ

4 Questions
Q-01 Is Packslip free to try?

The current build is a free planning tool while we refine it based on how people actually use it during a move.

Q-02 Does it work without an internet connection?

The core manifest and load-order features are designed to work offline, since moving day rarely has reliable signal in a stairwell or garage.

Q-03 Is my box list private?

A packing list is not sensitive data, but we still treat it that way — it stays on your device unless you choose to export or share it.

Q-04 Does Packslip replace hiring movers?

No. It's a planning layer for the packing and loading decisions you make yourself, whether or not professional movers are involved.
