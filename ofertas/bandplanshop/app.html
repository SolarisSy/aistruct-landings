Bandlog — a logging notebook that fits in a pocket

Bandlog is built around the same four fields every entry in this log already uses: date, time, frequency, and a short note on what was heard. It adds a place to track when a QSL card ships and when it finally comes back. That is the whole idea — no ranking, no social feed, no gear marketplace.

What it does

Six small pieces, each solving one part of keeping a log worth trusting later.

Dated entries

Every catch gets a timestamp automatically, so the log reflects when something actually happened, not when it was written up later.

Session timer

A simple running clock for a listening session, so notes stay attached to the right stretch of time instead of guessed after the fact.

Frequency field

A dedicated numeric field with tabular alignment, so a page of entries reads like a proper log rather than a scattered notes app.

Signal notes

Short free-text notes for strength, fading, and interference — the texture that a bare frequency number never captures.

QSL tracker

Mark a report as sent, then flip it to confirmed when a card or an e-QSL arrives. A quiet reminder if it has been quiet too long.

Plain export

Export the log as a plain text or CSV file at any time. The data is yours; nothing is locked to keep using the app.

How it works

Four steps, the same order every session follows on paper.

Start a session

Open the app when you sit down at the set. The timer starts; nothing else is required yet.

Log as you tune

Enter frequency, a short note on what came through, and let the timestamp fill itself in.

Mark reports sent

If a reception report goes out, flag the entry — Bandlog keeps a running list of what is still waiting on a reply.

Close the loop

When a QSL card or e-QSL arrives, mark it confirmed. The entry now has a beginning and an end.

Mini FAQ

Longer answers live on the full FAQ page.

Does Bandlog work without an internet connection?

Yes. Entries are stored locally first; syncing is only needed if you want a backup copy elsewhere.

Can I log more than shortwave broadcast stations?

The frequency field and notes are generic enough for amateur bands, utility stations, or anything else you tune across.

Is there a social or sharing feature?

Not at the moment. Bandlog is built as a private notebook first; export covers the case of sharing a log with someone directly.
