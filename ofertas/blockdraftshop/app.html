Blockbook

A notebook for the blocks you've already drafted — not a pattern generator. Blockbook exists to keep track of the block you corrected once, the adjustments that made it work, and how each version compares to the last, so the second garment doesn't start from zero.

See how it works Read the FAQ

What it's for

Block library

Store a bodice, sleeve, skirt, or trouser block with the measurements it was drafted from, so you can find "the one that fit" months later without re-measuring.

Version history

Every adjustment gets its own version instead of overwriting the last one — compare v2 and v3 side by side before deciding which is the new master.

Adjustment notes

Attach a short note to a change ("took 1 cm off the back shoulder seam") so the reason for an edit is still there a year later.

Piece checklist

Track which pieces belong to a block set — front, back, sleeve, facing — so nothing gets left off the cutting table.

Measurement log

Keep the body and garment measurements a block was drafted from together in one place, including notes on what was worn underneath.

Project linking

Connect a finished garment back to the block version it was cut from, so a fit note from the finished piece can feed back into the master block.

How it works

1

Log the block

Enter the measurements a block was drafted from, plus what layer of clothing was worn underneath while measuring.

A block without its source measurements is hard to trust six months later — Blockbook keeps the two together.

2

Record each adjustment

When a muslin reveals a fit issue, log the change and the reason for it against that block, not as a separate loose note.

The note travels with the block, so the next person to trace it (including future you) knows why it looks the way it does.

3

Compare versions

Pull up two versions of the same block side by side to see exactly what changed between the first draft and the current master.

Useful when a later project needs a slightly different ease and you want to branch off the master rather than edit it directly.

4

Cut from the master

Once a block is marked as the current master, every new project traces from it instead of a commercial pattern's average sizing.

A few questions

Does Blockbook draft the block for me?
No. Blockbook stores and organizes blocks you draft by hand or with a method of your choosing — it's a notebook, not a drafting engine.
Can I keep more than one block per garment type?
Yes — some people keep a fitted bodice block and a looser one for different projects, both stored with their own version history.
Is this only for clothing?
It's built around garment blocks, but the same version-and-notes structure works for any piece that gets adjusted and reused, like a bag lining or a slipcover pattern.
What happens to my measurements?
They're stored to support your own blocks. See the privacy policy for details on what's collected and why.
