What it does

Six things it keeps track of

1Signature order

A running list of each signature as it comes off the text block, in the order it was collated, so nothing gets reshuffled by accident.

2Fold condition notes

A short note per signature — sound, weak at the centerfold, needs a guard — attached to the number, not scattered across loose paper.

3Page counts

Expected page count per signature versus what is actually there, which catches a missing or misbound leaf early.

4Thread and station plan

Where sewing stations fall on each signature, kept consistent across the whole text block before the needle starts.

5Project history

A running note per project rather than per session, so picking a rebind back up after a week doesn't mean re-reading your own memory.

6A simple total

A plain count of verified signatures against the expected total, visible at a glance from across the bench.

How it works

Four steps, in the order you'd already do them

Signature Count follows the sequence most binders already use when disbinding and collating — it just keeps the notes in one place instead of on scrap paper next to the awl.

Start a project

Name the book and note the expected signature count if you have one from the original binding.

Log each signature

As the text block is disbound, add a line — number, page count, fold condition.

Flag what needs a second look

Weak folds or unexpected page counts get marked, not fixed in the moment.

Check the total before sewing

Verified count against expected count, so re-sewing starts from a text block you can trust.

Questions

A few things people ask

Does it replace a proper collation pass?

No. It is a place to record what a collation pass finds, not a substitute for doing the pass carefully by hand.

Is it built for a specific binding style?

It is neutral to structure — the same signature-and-fold logic applies whether the eventual sew is a kettle stitch or a longer link stitch.

Who is it for?

Mostly for people rebinding or repairing a text block with more than a handful of signatures, where memory alone starts to slip.
