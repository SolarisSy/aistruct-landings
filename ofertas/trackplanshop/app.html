Timetable Board

Timetable Board takes the plan you've already drawn — stations, sidings, a rough sequence of moves — and turns it into the paperwork an operating session actually runs on: waybills, a switch list per location, and a clock that keeps everyone honest about the time.

Built for the session, not the showcase

Most layout software is drawn for planning track. Timetable Board starts after the track is down — it's for the evening you actually want to run trains against a schedule, with jobs that have a beginning and an end.

Enter your stations and sidings once. Draft a running order. Timetable Board compiles the waybills and switch lists so the session paperwork is ready before anyone touches a locomotive.

What's inside

Six pieces of paperwork, handled once

Waybills

Generate a waybill for every wagon movement, tied to the origin, destination and commodity you set — printable or on screen.

Switch lists

Every pickup and set-out is compiled per location automatically, so the operator at each siding knows the job without guessing.

Session clock

A fast clock with a ratio you set, so a two-hour session can represent a full working day on the timetable.

Fiddle yard log

Track what's staged off-scene — road numbers, order, and what's due to re-enter and when.

Print & export

Plain paper cards for trackside use — no phone or tablet needed once the session paperwork is printed.

Layout library

Save more than one track plan and timetable — handy if you operate a shared club layout as well as your own.

How it works

From track plan to running session

Sketch your line

List your stations, yards and sidings, and roughly how far apart they sit. You don't need exact distances — just the order.

Draft a running order

Assign trains to time slots — a local, a goods working, a shunt move. Timetable Board lays them out against the fast clock.

Let the paperwork build itself

Waybills and switch lists compile from the running order automatically, ready to print before the session starts.

Run and log

Follow the board during the session and mark jobs done as you go — useful for spotting where a plan runs long or short.

Mini FAQ

Quick answers

Do I need a finished layout to use it?

No. Plenty of readers use Timetable Board to draft a running order before a single piece of track is laid, as a way to test whether a plan gives them enough to do.

Does it work for any scale or gauge?

Yes. Timetable Board doesn't care about scale — it works from your station list and running order, so it applies equally to N, HO, OO or larger.

Can I use it without an internet connection at the layout?

You can print the waybills, switch lists and session card ahead of time and run the whole session on paper if that suits your space better.

Is this only for solo operators?

Not at all — the switch lists are written so several operators can each work from their own location without needing to see the whole timetable.
