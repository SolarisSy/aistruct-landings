Política de Privacidade

Como o Orçamento Já trata os dados de quem acessa este site e usa a ferramenta.

Última atualização: julho de 2026

1. Quem trata os dados

Esta política se aplica ao site e à ferramenta Orçamento Já, acessados em orcamentoja.click. Dúvidas sobre esta política podem ser enviadas para contato@orcamentoja.click.

2. Que dados coletamos

Coletamos apenas dados técnicos de acesso ao site, coletados de forma automática pelo navegador:

  • Endereço IP e localização aproximada (cidade/estado), usados para estatística de acesso.
  • Tipo de dispositivo, navegador e sistema operacional.
  • Páginas visitadas e tempo de permanência, para entender quais conteúdos são úteis.
  • E-mail informado voluntariamente no campo de aviso de novidades, quando preenchido.

Os valores digitados dentro da ferramenta de orçamento (categorias, metas, gastos) não são dados bancários — não pedimos nem armazenamos senha de banco, número de cartão ou acesso a conta corrente.

3. Cookies e medição

Usamos cookies próprios e de terceiros com finalidade de medição de audiência — entender quantas pessoas visitam o site e por qual origem chegaram até ele. Esses cookies não são usados para venda de dados a terceiros.

É possível bloquear cookies diretamente nas configurações do navegador. Bloquear cookies pode limitar alguns recursos deste site, mas não impede a navegação básica.

4. Para que usamos os dados

  • Manter o site funcionando de forma estável e segura.
  • Entender quais páginas e recursos são mais acessados, para priorizar melhorias.
  • Responder a mensagens enviadas por e-mail para o endereço de contato.
  • Enviar o aviso de novidades para quem se cadastrar voluntariamente, sem uso para outra finalidade.

5. Compartilhamento com terceiros

Não vendemos dados de acesso a terceiros. Dados de medição podem ser processados por provedores de infraestrutura e de estatística de audiência, unicamente para os fins descritos nesta política.

6. Seus direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode solicitar, a qualquer momento, a confirmação da existência de tratamento, o acesso aos seus dados, a correção de dados incompletos ou desatualizados, e a eliminação dos dados tratados com base no seu consentimento — como o e-mail do aviso de novidades.

Para exercer qualquer um desses direitos, envie uma mensagem para contato@orcamentoja.click descrevendo o pedido.

7. Retenção e segurança

Dados técnicos de acesso são mantidos pelo prazo necessário para as finalidades de estatística descritas acima e depois descartados. Adotamos medidas técnicas razoáveis para proteger os dados tratados contra acesso não autorizado.

8. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no site ou na legislação aplicável. A data no topo desta página indica a versão mais recente.
